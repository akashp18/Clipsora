# Caption Quality Audit — Classic vs Studio

Date: 22 November 2026. Scope: the caption pipeline at the point before the Caption Studio change, compared with
the Classic workspace and the exported MP4.

## Executive finding

Classic and Studio did **not** have separate caption renderers. Both resolve `studio/styles.py` presets through
`studio/render.py`; for the same preset and transcript the ASS file and MP4 are identical. The regression was in
the Studio editing surface and in the default typographic composition:

1. The Studio clip editor showed the raw MP4 with **no caption preview at all**. Classic's style picker showed the
   actual type; Studio reduced the whole system to a `<select>` and two look fields.
2. Studio did not load Poppins, Anton, or Archivo Black, so a faithful in-browser preview was impossible even if
   an overlay had existed.
3. The Studio editor only sent `style` and `layout` on save. Per-caption settings could be read from an old clip
   but could not be authored in the new UI, and there was no manual emphasis control.
4. The export grouped words with a greedy count and a 16-character guard. This produced orphans such as
   `I THINK WE` / `SHOULD BE` and split phrases on weak boundaries. `_lines` also shrank a phrase before trying a
   second line, making long words needlessly tiny.
5. There was no preview/render parity test. A style could be changed in the editor without any evidence that the
   MP4 saw the same family, size, casing, position, or grouping.

`/classic` remains a separate workspace and was not reworked. Its saved projects still use the same style IDs and
the same renderer; no caption style was renamed or removed.

## What was lost, changed, simplified, or disconnected

**Lost:** live caption preview, direct typographic authoring, visible emphasis, safe-area guidance, and a sense of
the caption as part of the frame. The old picker's small previews were crude, but they were more useful than a
plain select because they showed the type and active colour.

**Changed:** the current presets had drifted toward maximum size and maximum words per group. A `max_words` value
was treated as a target rather than a ceiling, so five-word Classic groups wrapped into dense blocks. The corrected
defaults are documented above; the style names and identities remain.

**Simplified:** settings existed in the schema but not in the Studio UI. The new Caption Studio exposes them at the
point of editing, with essential controls first and advanced colour/stroke controls behind a disclosure.

**Disconnected:** Studio did not load the caption fonts and did not render an overlay. The preview and the export
were two unrelated surfaces.

## Corrections made

- Bundled `/assets/fonts/*.ttf` route and `@font-face` declarations shared by the overlay.
- A 9:16 video frame with a caption layer that follows `currentTime`, the same preset, the same word groups, and
  the same active-word rule as the ASS renderer.
- Live style gallery with real typographic previews (no generic icons).
- Controls for family, size, letter spacing, line height, words per group, capitalisation, position, stroke,
  shadow, panel opacity/colour, four colours, animation, duration, intensity, emphasis, and safe guides.
- Undo/redo and reset-style without destroying settings on tab switches.
- Balanced grouping at sentence/pause boundaries; no orphan group when a balanced split exists.
- Wrap-before-shrink line breaking; word order is always preserved (the first balancing attempt reordered words
  and was rejected after the contact sheet exposed overlapping groups).
- `letter_spacing` added to the shared spec, ASS Spacing column, browser letter spacing, tests, and validation.
- Manual `highlight_words` accepted by re-render and persisted as part of the clip.

## Remaining limits

- Browser CSS and libass are different rasterisers. Geometry and type are aligned, but glyph antialiasing, stroke
  joins, and letter-spacing accumulation are not pixel-identical. Parity is checked perceptually, not by pixel diff.
- The test-pattern frames are useful for geometry and contrast but are not a substitute for every real podcast
  composition. Two moving examples are included; a human creative review is still required for footage with faces.
- Face-aware caption avoidance and automatic emphasis selection remain outside this pass; placement is manual and
  stable, with safe guides.
